# ELITE Design System, Brand Tokens V3 (23-09-2026)

Source: `ELITE_Brand-Tokens_23-09-2026_0315_V3.md` (08_Templates-Branding\Brand-Tokens). Gold is retired. Sand is the single accent. Dark mode first.

## Colour (exact hex only, no near-misses)
| Role | Hex |
|---|---|
| Ground | Espresso 800 `#171710` (deepest `#0C0B08`) |
| Raised / card | Espresso 700 `#211E17` |
| Display text | Isabelline `#F8F2EB` |
| Body text | `#D9D0C4` |
| Muted text (18px+ only) | Taupe 300 `#8C7B6B` |
| Accent (kickers, rules, chips, CTA fill) | Sand `#E6D4BC` |
| Accent hover / secondary | Sand 200 `#C4B5A3` |
| Hairline | `rgba(230,212,188,.22)`, strong `.45` |
| Scrim over photography | 105deg gradient `rgba(12,11,8,.82)` to `.35` at 55% to `.10` |

CTA button: Sand fill, Espresso `#171710` text. Never use `#C7A34A`, `#D4B07C`, `#F0E8D5`, `#1A1A1A` or any retired value.

## Type
- Display / headlines: Marcellus (video scale: 96 to 120px, line-height 1.2)
- Body / UI: Barlow (body 36px+ on 1080x1920, weight 400, subheads 600)
- Metadata, address and contact lines: Quicksand
- Embed all fonts locally in the project; no render-time network fetches.

## Layout and motion
- 1080x1920, 96px side gutters, keep captions and key content inside the platform safe zones.
- Radius 2 / 4 / 8. Spacing 4, 8, 16, 24, 32, 48 (scale up for video).
- Slide change: horizontal swipe, 450ms ease-out, no bounce. Sand progress dots across the top.
- Sell the feeling first, facts follow in small sans. No emojis, no hype, Australian spelling.
- No invented data. Empty state or verified content only.
